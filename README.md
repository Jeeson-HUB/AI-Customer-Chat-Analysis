# AI Chat Sentiment & Customer Analysis

## Project Overview

This project is an AI-powered customer support analytics system built using Python, HuggingFace Transformers, and Streamlit.

The system analyzes customer chat messages to identify sentiment, classify topics, and generate visual insights.

---

## Features

* AI Sentiment Analysis using HuggingFace
* Topic Classification
* Interactive Streamlit Dashboard
* Real-Time Customer Message Prediction
* Data Visualization using Matplotlib & Seaborn
* Customer Chat Analytics

---

## Technologies Used

* Python
* Pandas
* Streamlit
* HuggingFace Transformers
* Matplotlib
* Seaborn

---

## Dataset

A mock customer support dataset containing 200 customer messages was used for analysis.

---

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit app:

```bash
streamlit run app.py
```

---

## Project Output

The dashboard provides:

* Sentiment Distribution
* Topic Distribution
* Sentiment per Topic
* Real-Time AI Message Analysis
